# É Esse Ascendant Path

🚀 NOME DO APP:

Ascensão

🎨 TEMA VISUAL:

 Modo escuro obrigatório

 Estilo inspirado em sistema de RPG (Solo Leveling UI)

 Cores:

 Roxo neon (#7B2FF7)

 Azul profundo (#0F172A)

 Preto (#020617)

 Efeitos:

 Glow suave

 Bordas iluminadas

 Animações fluidas

 Sensação de “interface viva”

🧍 SISTEMA DO JOGADOR

Criar perfil com:

 Avatar (upload)

 Nível

 XP (barra de progresso animada)

 Rank (E → D → C → B → A → S → Monarca)

 Ouro (moeda)

 Sequência (streak de login)

 Título (ex: “Renascendo das Cinzas”)

📅 SISTEMA DE LOGIN DIÁRIO

Botão: “Registrar Dia”

Regras:

 Login realizado → +10 XP

 Dia perdido → -50 XP

 2 dias perdidos → -100 XP acumulado

Reset diário às 00:00

Feedback:

 ✔️ “Dia registrado”

 ⚠️ “Dia perdido — XP reduzido”

📊 PAINEL DO SISTEMA (LADO DIREITO)

Exibir:

 🔥 Sequência atual

 🎁 Bônus ativo (ex: 1.2x XP)

 ⚠️ Avisos do sistema

 🎯 Missões pendentes

 🔓 Próximo nível / desbloqueio

Mensagem dinâmica:

“Seu progresso está instável. Continue ou regrida.”

📋 SISTEMA DE MISSÕES (TAREFAS)

Cada tarefa deve ter:

 Nome

 Tipo (Estudo, Treino, Leitura, etc)

 Dificuldade:

 Fácil

 Normal

 Difícil

 Horário (início e fim)

⚙️ REGRAS:

XP baseado no tempo:

 Fácil → tempo × 0.2

 Normal → tempo × 0.5

 Difícil → tempo × 1

Ouro:

 1 hora = 50 de ouro

Funções:

 Marcar como concluída

 Mostrar:

 XP ganho

 Ouro ganho

 Tempo

⏳ TIMER (POMODORO)

 50 minutos foco

 Pausa curta

 Pausa longa

Botões:

 Iniciar

 Pausar

 Resetar

🧬 SISTEMA DE HÁBITOS

Criar hábitos com:

 Nome

 Ícone

 Cor

 Data final

⚖️ REGRAS:

 Concluir → ganha XP

 Falhar → perde o dobro

Exemplo:

 +50 XP / -100 XP

Botões:

 ✔️ Concluído

 ❌ Falhou

🔥 HEATMAP DE HÁBITOS

Visual mensal:

 Verde → concluído

 Vermelho → falhou

 Cinza → vazio

🎯 SISTEMA DE PROGRESSÃO (PORTÕES)

 Cada nível exige XP

 Mostrar progresso atual

Mensagem:

“Você ainda não está pronto.”

⚔️ SISTEMA DE DESAFIOS

 Tarefas com múltiplas etapas

 Todas precisam ser concluídas

Regra:

 Falhou → reinicia tudo

🧠📓 SISTEMA DE JOURNALING (ESCRITA LIVRE)

⚠️ IMPORTANTE:

 NÃO gerar perguntas automáticas

 NÃO sugerir textos

 NÃO interferir

📓 DIÁRIO

Criar sistema de escrita livre com:

 Data automática

 Campo de texto grande (sem limite)

 Emoção (opcional — emoji ou seleção)

 Intensidade emocional (1 a 10)

⚙️ REGRAS:

 Escrever no diário → +20 XP

 Entrada longa (detectar por tamanho) → +10 XP extra

🌑 MODO PROFUNDO

Botão: “Modo Profundo”

Quando ativado:

 Interface escurece mais

 Remove distrações

 Foco total no texto

Recompensa:

 +30 XP adicional

🧠 SISTEMA DE INSIGHT

Após vários registros:

Mostrar padrões como:

 Frequência de escrita

 Variação emocional

 Consistência

Exemplo de mensagem:

“Você escreve mais quando está sob pressão.”

🧘 PÁGINA DE DESPERTAR

Página fixa com campos editáveis pelo usuário:

 Quem você quer se tornar

 O que você rejeita

 Qual dor você aceita

🎁 SISTEMA DE RECOMPENSAS

Criar loja:

 Tempo livre (1h) → 150 ouro

 Jogar → 50 ouro

Botão:

 Resgatar

📜 HISTÓRICO (LOG)

Mostrar:

 Tarefas concluídas

 XP ganho

 Ouro acumulado
