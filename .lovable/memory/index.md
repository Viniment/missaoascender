# Project Memory

## Core
App "Ascensão" — guia de desenvolvimento pessoal focado em amor-próprio, autoestima, autoconfiança, diálogo interno e coragem. NÃO é produtividade militar, NÃO é coach.
Voz única: Pai Interior sábio — corrige sem humilhar, acolhe sem consolar em excesso, responsabiliza sem cobrar.
Conceitos: Pai Interior, Zona de Conforto (cobra preço silencioso), Jardim Interior (pensamentos são sementes), Diálogo Interno ("você falaria isso a alguém que ama?").
Falha → "teve uma dificuldade hoje, o que aprendemos?" Nunca humilhar. Autocrítica → reformular, não reforçar.
Tom: caloroso, humano, profundo, sábio, gentil, encorajador. Sem militarização, sarcasmo, positividade tóxica.
Primary #7B2FF7 (neon purple), bg #020617/#0F172A. Fonts: Orbitron (display), Rajdhani (body). Dark mode only.
State em localStorage via useGameStore + GameContext. Linguagem: PT-BR.
Datas sempre Brasília (getTodayBrasilia).
